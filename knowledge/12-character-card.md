# 12 · 角色卡完整模板

角色卡是角色一致性的唯一事实源。它同时服务两个消费者：**人**（作者、AI 写作时的人设锚点）与**脚本**（`character_tracker.py` / `validate_character.py` 的红线校验）。

设计原则：**主角卡要厚（行动线、碰撞对象必填），配角卡要薄（可只填核心字段）。**

---

## 一、完整字段表（17 字段）

| # | 字段 | 必填 | 说明 | 对应 JSON 键 |
|---|------|------|------|--------------|
| 1 | 角色ID | 是 | 全局唯一，格式 `CH-xx` | `id` |
| 2 | 姓名 | 是 | 角色名 | `name` |
| 3 | 性别 | 是 | 男 / 女 | `gender` |
| 4 | 角色类型 | 是 | 男主 / 女主 / 男配 / 女配 / 男反派 / 女反派 | `role` |
| 5 | 身份 | 是 | 社会/职业身份（如「青云宗外门弟子」） | `identity` |
| 6 | 地位 | 是 | 在当前世界中的层级（如「底层」「中层」「顶层」或具体职级） | `status` |
| 7 | 外貌特征 | 是 | 1–3 个可辨识特征（忌流水账） | `appearance` |
| 8 | 性格核心 | 是 | 14 种词库选 2–3 个组合，或自填 | `personality` |
| 9 | 背景故事 | 次要 | 简要，2–3 句；只写影响当前行动的部分 | `background` |
| 10 | 核心目标 | 次要 | 简要，一句话 | `goal` |
| 11 | 人物关系 | 是 | 与其他角色的关系，键值对 | `relations` |
| 12 | 成长轨迹 | 选填 | 从起点到终点的变化弧线 | `growth_arc` |
| 13 | 五维性格DNA | 选填 | AI 推导，用户可覆盖；格式见第二节 | `personality_dna` |
| 14 | 行为红线 | 是（≥1 条） | 角色绝不会做的事，供脚本校验 | `red_lines` |
| 15 | 语音指纹 | 选填 | AI 推导，用户可覆盖；格式见第二节 | `voice_fingerprint` |
| 16 | 行动线 | 主角必填 | 他想要什么 / 他会怎么做 / 行动线走向 | `action_line` |
| 17 | 碰撞对象 | 主角必填 | 会与哪些角色碰撞 / 碰撞原因 | `collision_targets` |

> 注：`id` 作为独立字段计入，使总字段数为 17；`character_tracker.py` 与 `validate_character.py` 均以 `name` 为匹配键，`red_lines` 为校验源。

> 性格核心从 `knowledge/06-personalities.md` 的 14 种性格中选 2–3 个组合，或自填（自填时 AI 追问 1–2 个关键问题明确行为表现）。

## 二、选填字段格式参考

### 五维性格DNA

采用大五人格（OCEAN），每维 0–10 分，用 `/` 分隔：

```
外向性/6 + 尽责性/8 + 神经质/3 + 开放性/7 + 亲和性/5
```

| 维度 | 低分（0–3） | 高分（7–10） |
|------|-------------|--------------|
| 外向性 | 独处、寡言 | 健谈、爱社交 |
| 尽责性 | 随性、拖延 | 自律、守约 |
| 神经质 | 情绪稳定 | 易焦虑、易怒 |
| 开放性 | 守旧、务实 | 好奇、爱幻想 |
| 亲和性 | 冷漠、好胜 | 友善、利他 |

> AI 可依据 `personality`（性格核心）自动推导 DNA；用户可覆盖。推导仅作起点，不强制。

### 语音指纹

描述角色「怎么说话」，用于对话写作与台词一致性校验：

```
语速偏快 / 常用"啧""得嘞" / 句式偏好短句 / 潜台词倾向吐槽 / 典型用词"离谱""不是吧"
```

推荐拆成 5 个可写字段：
- `speech_rate`：语速（偏快 / 偏慢 / 适中）
- `catchphrases`：口头禅（字符串数组）
- `sentence_pref`：句式偏好（短句 / 长句 / 反问 / 排比）
- `subtext_style`：潜台词倾向（吐槽 / 反讽 / 回避 / 直给）
- `signature_words`：典型用词（字符串数组）

## 三、主角类型选项

主角类型决定「行动线」的组织方式。写作前必须明确选择，因为它直接影响碰撞对象的分配与叙事视角。

| 类型 | 适用场景 | 对行动线结构的影响 |
|------|----------|--------------------|
| 单一主角 | 爽文、升级流、复仇流、第一人称代入 | 一条主线，所有碰撞对象围绕主角；配角行动线仅作为「碰撞源」存在 |
| 双主角 | 双强对决、双线叙事、阵营对立、CP 向 | 两条平行行动线，需设计「必然交汇点」；碰撞对象分属两线并最终对撞 |
| 群像 | 史诗、权谋、战争、多阵营 | 多条行动线并行，主角不唯一；每条线有自己的欲望与阻力，靠「碰撞网」编织 |

### 选择建议
- **单一主角**：作者想强代入、快节奏、单点突破时选。风险是配角单薄。
- **双主角**：两个核心欲望需要对照时选（如「复仇 vs 守护」）。风险是双线失衡。
- **群像**：世界观本身就是卖点时选。风险是视角混乱、读者抓不住主线，需明确「第一视角」作为锚。

> 行动线数据落盘于 `.novel/state/action-lines.json`，碰撞关系落盘于 `.novel/state/collision-points.json`，字段见下节 JSON 示例。

### 4.2 JSON 数据结构示例

与 `.novel/state/characters.json` 对齐；扩展字段（`action_line` 等）供 agent 使用，`red_lines` 为 `validate_character.py` 的校验源。

```json
{
  "characters": [
    {
      "id": "CH-01",
      "name": "林凡",
      "gender": "男",
      "role": "男主",
      "identity": "青云宗外门弟子",
      "status": "底层",
      "appearance": ["左眉一道旧疤", "常年灰布衣", "眼神沉"],
      "personality": "沉稳 + 理性 + 阴狠",
      "background": "出身寒门，母亲临终留下半枚玉佩，遗言未尽。为查明母亲死因入青云宗。",
      "goal": "查明母亲死因，登临大道",
      "relations": {
        "苏浅浅": "退婚对象→同伴",
        "血煞老祖": "仇敌"
      },
      "growth_arc": "隐忍求生 → 锋芒初露 → 执掌一方",
      "personality_dna": {
        "extraversion": 4,
        "conscientiousness": 8,
        "neuroticism": 3,
        "openness": 7,
        "agreeableness": 5
      },
      "red_lines": [
        "不会主动认输",
        { "forbidden": ["滥杀无辜", "背弃同伴"] }
      ],
      "voice_fingerprint": {
        "speech_rate": "偏慢",
        "catchphrases": ["行", "记下了"],
        "sentence_pref": "短句",
        "subtext_style": "克制",
        "signature_words": ["分寸", "代价"]
      },
      "action_line": {
        "want": "查明母亲死因并复仇",
        "how": "隐忍蛰伏，借宗门资源快速变强，步步为营",
        "direction": "由被压迫者成长为能掀桌的人"
      },
      "collision_targets": [
        { "with": "苏浅浅", "reason": "退婚旧怨 + 被迫同行" },
        { "with": "血煞老祖", "reason": "母亲之死的直接凶手" }

```

> `red_lines` 支持两种写法：字符串（`"不会主动认输"`）或结构化（`{"forbidden": ["滥杀无辜"]}`）。`validate_character.py` 会去除「不会/不能/不得/绝不/严禁」前缀后匹配正文。
